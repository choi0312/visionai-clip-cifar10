# Third-party sources and figure attribution

- **CLIP checkpoint:** `openai/clip-vit-base-patch32` by OpenAI, revision `3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268`, downloaded from [Hugging Face](https://huggingface.co/openai/clip-vit-base-patch32). Weights are not redistributed here. The model card has no explicit license tag. The separate [official CLIP source repository](https://github.com/openai/CLIP) carries MIT. Configuration, tokenizer and processor files in `results/processor/` and `results/model_config.json` derive from this checkpoint; no separate license is asserted for those files.
- **CIFAR-10:** Alex Krizhevsky, Vinod Nair and Geoffrey Hinton. [Official data page](https://www.cs.toronto.edu/~kriz/cifar.html). Cite Alex Krizhevsky, *Learning Multiple Layers of Features from Tiny Images*, 2009. Archive and full images are not redistributed. Eight original 32×32 test images (indices 0, 52, 223, 295, 5, 9, 3524, 5603) are retained as educational examples in `results/example_pixels.npz` and enlarged with nearest interpolation in `figures/predictions.png`; predictions, indices and class labels were added. Rights in the original images remain with their respective holders. The official page does not provide a blanket image license that we can reassign.
- **Model card screenshot:** `figures/model_card_excerpt.png` is a crop of the actual [Hugging Face model page](https://huggingface.co/openai/clip-vit-base-patch32), captured 2026-11-08. It preserves the visible model name and task badges. The page and trademarks retain their original rights.
- **Experiment charts:** `prompt_comparison.png`, `confusion.png` and `candidate_omission.png` were generated from saved GPU logits. The charts contain measured results rather than generated/synthetic photos. `code_excerpt.png` is an edited excerpt/summary of the actual algorithm and saved outputs, not a terminal screenshot. Details are in `results/figure_credits.json`.

The MIT license in this repository applies to its original experiment code. It does not relicense the checkpoint, dataset, screenshot, tokenizer assets or other third-party material.
